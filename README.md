# DHODH multi-omics analysis

This repository contains the bioinformatics workflow used to analyze
transcriptomic, proteomic, and metabolomic data from AC16 cardiomyocytes and
iPSC-derived cardiomyocytes (iPSC-CM) carrying or correcting the heterozygous
DHODH R135C C/T variant.

The analysis supports the manuscript project on inflammation-dependent
mitochondrial cardiomyopathy susceptibility. The code focuses on differential
omics analysis, pathway enrichment, MitoCarta/glycolysis summaries, and
multi-omics C/T versus C/C clustering figures.

## Main Workflow

Run the main analysis from the repository root:

```r
quarto::quarto_render("DHODH_analysis_main.qmd")
```

For interactive execution, source the project scripts in this order:

```r
source("02.Rscripts/config.R")
source("02.Rscripts/library.R")
load_project_libraries()
source("02.Rscripts/transcriptomic.R")
source("02.Rscripts/proteomic.R")
source("02.Rscripts/metabolomic.R")
source("02.Rscripts/enrichment.R")
source("02.Rscripts/clustering.R")
```

## Analysis Modules

- `library.R`: central package loader. This is the only cleaned script that
  should call `library()`.
- `config.R`: project paths, thresholds, comparisons, colors, and figure
  settings.
- `transcriptomic.R`: DESeq2 normalization, QC, and DEG generation.
- `proteomic.R`: limma-based DEP generation for AC16 and iPSC-CM proteomics.
- `metabolomic.R`: limma-based DEM generation and metabolomics QC.
- `enrichment.R`: Reactome GSEA, g:Profiler ORA, and MitoCarta summaries.
- `plots.R`: reusable QC, volcano, and MitoCarta/glycolysis plotting helpers.
- `clustering.R`: reusable multi-omics C/T versus C/C clustering heatmaps,
  legends, omic-composition plots, and Reactome ORA helpers.

## Main Thresholds

- Transcriptomics DEG: `padj <= 0.05` and `abs(log2FoldChange) >= 1.5`
- Proteomics DEP: `adj.P.Val <= 0.05` and `abs(logFC) >= 0.58`
- Metabolomics DEM: `adj.P.Val <= 0.05` and `abs(logFC) >= 0.58`
- Metabolomics quality filter: keeps `Qual. < 4`, excluding markers 4, 5, and 6

## Key Outputs

Clean outputs are written under `03.Results/`, including:

- DEG, DEP, and DEM result tables
- QC PCA and heatmap plots
- volcano plots
- GSEA and g:Profiler enrichment outputs
- MitoCarta pathway summaries
- MitoCarta plus KEGG/Reactome glycolysis volcano plots
- multi-omics C/T versus C/C clustering heatmaps and separate shared legends

## Reproducibility Notes

The cleaned workflow was organized to preserve manuscript-producing results.
For each omics layer, old versus clean outputs were checked at the manuscript
significance thresholds to confirm identical DEG/DEP/DEM calls and directions.

Package loading is centralized in `02.Rscripts/library.R`. Missing packages are
reported explicitly and should be installed before running the workflow.
